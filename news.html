14 / 2 / 2026 DEVELOPMENT

Migblock Alpha (v0.0 – v0.2.1)

As of the 5th of February 2026, Migblock is open for Playtesting! ~ I know, finally!

The following is everything you need to know:

  • We are starting from scratch, as we've a new vision for the Game. As such, you shall be able to see the Game grow immensely over the next few months.
  • We're going to release things as we make them, so the Game is going to change rather quickly.
  • We'll be hosting a Public Server where all are welcome, although you're quite welcome to host your own - we're happy to help with this if you need.

This is where your Feedback is going to be crucial!

So please do let us know anything and everything that you think about the Game. Please try and break it and tell us what you think!

Please join our Community, make suggestions and report bugs on Discord: https://discord.gg/KShabrZgHq
